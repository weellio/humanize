# Guides

Pick the guide for what you're writing.

| You're writing | Guide |
|---|---|
| Emails: replies, cold emails, follow-ups, saying no | [emails.md](emails.md) |
| Documents: reports, proposals, memos, how-tos, cover letters | [documents.md](documents.md) |
| Presentations: slides, speaker notes, talk scripts | [presentations.md](presentations.md) |

Posts, articles and captions need no guide. The prompts handle those by default.

## Before you start

Load one of the prompts into your chat app first. The main [README](../README.md) shows where each one goes in
ChatGPT, Gemini, Claude and the rest. The guides assume it's loaded.

Each guide has:

- what changes for that format
- prompts to copy and paste, with `[brackets]` for you to fill in
- a before and after
- how to check the result

## Two rules for every format

**Brackets in the output mean the model needed a fact you didn't give it.** Fill them in yourself or delete the
sentence. Don't ask the model to fill them in. It will make something up, and made-up numbers in a report or
an email are worse than vague ones.

**Read it out loud once before you send it.** If you wouldn't say a sentence to the person, change it.
